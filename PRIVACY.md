# Privacidad de la versión 0.1

La app guarda en el navegador nombre opcional, frases, rutina y conteos de actividades. No tiene backend propio, anuncios, analítica ni login propio. El proveedor de alojamiento puede generar registros técnicos de visitas y tener sus propias políticas.

La función de voz usa la síntesis del navegador; algunas voces pueden depender de conexiones o servicios del sistema. No asumir que toda síntesis es local.

Los respaldos JSON contienen la configuración. Mantenerlos privados. El dispositivo compartido permite acceder a los datos: el botón Familia no tiene autenticación.

El service worker guarda archivos de la aplicación para uso offline. Para eliminar todo, borrar datos y almacenamiento del sitio desde el navegador. Cambiar de navegador o dominio no migra la información automáticamente.

En GitHub usar exclusivamente ejemplos ficticios. Nunca publicar historias clínicas, nombres, imágenes o grabaciones de menores. Si detectas datos expuestos, evita reproducirlos y avisa al mantenedor con una descripción general.
