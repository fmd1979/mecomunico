# Cómo contribuir

Puedes aportar programación, diseño accesible, revisión de contenidos, traducciones o pruebas de uso. No es necesario programar para participar.

1. Revisa las tareas de ROADMAP.md y los issues existentes.
2. Abre un issue describiendo un problema u objetivo concreto. Para cambios grandes, conversa antes de implementarlos.
3. Haz un fork, crea una rama y modifica solo lo necesario.
4. Ejecuta `node scripts/check.mjs` y prueba las pantallas afectadas.
5. Envía una pull request explicando el cambio y cómo lo probaste.

## Criterios de revisión

- Texto claro, controles grandes, etiquetas accesibles y navegación con teclado.
- Respeto por edad, decisiones y preferencias; no infantilizar por diagnóstico.
- No exigir voz clara para completar actividades o comunicarse.
- Evitar animaciones obligatorias, sonidos inesperados y reproducción infinita.
- Mantener compatibilidad offline y rutas relativas para hosting en subdirectorios.
- No incorporar rastreadores, envío de información o dependencia externa sin explicar y revisar sus consecuencias.
- No presentar ejercicios como tratamientos ni métricas como diagnósticos.

Para contenido educativo, explicar habilidad objetivo, nivel requerido, apoyos y forma de observar resultados. La revisión profesional no equivale a validación clínica.

Usa datos ficticios. No adjuntes información personal, fotos o audio de menores. Los aportes deben ser propios o contar con licencia compatible y atribución.

Las contribuciones se ofrecen bajo la licencia MIT del proyecto. El mantenedor revisa cambios antes de integrarlos; abrir una PR no garantiza aceptación.
