# Compatibilidad y pruebas — v0.1.1

Implementado: PWA standalone, icono Apple de 180 px, metadatos de iOS, áreas seguras, diseño de tablets y ventanas estrechas, orientación libre e instrucciones de instalación.

Pendiente de verificar en dispositivos reales:

|---|---|---|---|---|
| iPhone / Safari | Pendiente | Pendiente | Pendiente | Pendiente |

| Tablet Android / Chrome | Pendiente | Pendiente | Pendiente | Pendiente |
| Teléfono Android / Chrome | Pendiente | Pendiente | Pendiente | Pendiente |

Probar ancho 320/375/768/1024 px, orientación horizontal y vertical, TalkBack/VoiceOver, voz después de tocar un botón y modo avión después de la carga inicial. Verificar comunicación, rutina, exportación/restauración y actualización desde v0.1.0.

La voz puede necesitar conexión o voces descargadas. Los datos quedan por navegador/origen; instalar la app puede usar un almacenamiento distinto según el sistema. Exportar respaldo antes de cambiar de entorno. El sistema puede eliminar cachés: offline no es una garantía permanente.

Instrucciones oficiales: https://support.apple.com/en-eg/guide/iphone/iphea86e5236/ios y https://support.apple.com/en-my/guide/ipad/ipad8f1f7a29/ipados
