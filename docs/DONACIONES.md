# Preparar un canal de apoyo

La página invita a colaborar o proponer patrocinio. **Aún no cobra ni recibe donaciones.**

Antes de habilitar un botón de pago:

1. Elegir y verificar un canal disponible para el responsable en Ecuador (p. ej. enlace de pago de su proveedor). Confirmar comisiones, retiro y condiciones vigentes directamente con el proveedor.
2. Definir quién recibe los fondos y el destino previsto: alojamiento, accesibilidad, revisión de contenidos o pruebas.
3. Publicar una política sencilla: voluntariedad, contacto para consultas, condiciones del proveedor y registros de uso de fondos.
4. Usar un enlace de pago alojado por el proveedor; no pedir datos de tarjeta desde la PWA estática.
5. Añadir el enlace real a `dist/index.html` y probarlo antes de anunciarlo.

No asumir que las aportaciones son deducibles de impuestos ni que existe una fundación registrada. No presentar una donación como compra de terapia ni como garantía de resultados.
