# Invitación a colaborar

Estamos iniciando MeComunico: una aplicación web y PWA abierta para apoyar comunicación, rutinas y aprendizaje cotidiano.

La primera versión incluye mensajes con voz, agenda visual y actividades breves. Queremos mejorarla junto con familias, personas usuarias, docentes, terapeutas de lenguaje, diseñadores y programadores.

No promete curas ni sustituye atención profesional. Buscamos herramientas útiles, respetuosas de la edad y adaptables a cada persona.

Puedes colaborar probando Android, revisando accesibilidad, proponiendo ejercicios o enviando una pull request. Revisa CONTRIBUTING.md y ROADMAP.md en el repositorio.

Comparte experiencias usando ejemplos ficticios y sin datos personales de menores.

¡Una pequeña contribución también cuenta!
